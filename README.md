# Sistema de Gestión de Clientes

Este proyecto es una aplicación desarrollada en Python para la administración y gestión de información de clientes. Permite registrar, consultar, actualizar y gestionar datos de manera eficiente.

---

## 🚀 Características

* Registro de nuevos clientes.
* Consulta y búsqueda de registros.
* Actualización de datos de clientes existentes.
* Estructura modular del código orientada a buenas prácticas.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Python 3.x
* **Control de Versiones:** Git & GitHub
